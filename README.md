## 📌 Tasks & Solutions Overview

| # | Question / Task | Description & Constraints |
|---|---|---|
| **1** | **Total Transaction Value** | Calculate total transaction value from `transactions = [1200, 450, 800, 1500, 2300, 700, 100]` without using `sum()`. |
| **2** | **Highest & Lowest Transaction** | Find the highest and lowest transaction values without using `max()` and `min()`. |
| **3** | **Average Temperature** | Compute the average temperature from `temperatures = [32, 35, 28, 40, 38, 31, 42]`. |
| **4** | **Student Marks Categorization** | Categorize student marks (`marks = [78, 92, 45, 67, 88, 53, 99]`) into `90+`, `75–89`, `50–74`, and `<50`. |
| **5** | **Login System (3 Attempts)** | Implement a secure login mechanism allowing up to 3 password attempts using a `while` loop. |
| **6** | **Product Price Filtering** | Filter and display products costing more than ₹2,000 from a dictionary. |
| **7** | **Accept 10 Numbers into List** | Store 10 numbers entered by user into a list using a loop with error handling. |
| **8** | **Character Frequency Counter** | Count frequencies of every character in a string without using `collections.Counter`. |
| **9** | **Second-Largest Number** | Determine the second-largest distinct number in a list without using `sort()`. |
| **10** | **Palindrome Checker** | Verify whether a given string is a palindrome using a loop (two-pointer technique). |
| **11** | **Number Pattern Generator** | Generate a half-pyramid number pattern (`1`, `12`, `123`, `1234`, `12345`). |
| **12** | **ATM Simulation System** | Interactive and simulated ATM system supporting Balance Check, Deposit, Withdrawal, and Exit. |
