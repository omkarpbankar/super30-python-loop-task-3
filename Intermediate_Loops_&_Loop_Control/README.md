# Intermediate Loops & Loop Control

This folder contains exercises and solutions focused on **intermediate loop control structures** in Python, including `for`, `while`, `break`, `continue`, `for-else`, `range()`, `enumerate()`, and nested loops.

---

## 📌 Tasks & Solutions Overview

| # | Question / Task | Description & Control Mechanism |
|---|---|---|
| **1** | **Skip Multiples of 5** | Print numbers 1–100 skipping multiples of 5 using `continue`. |
| **2** | **First Divisible by 7 and 11** | Iterate 1–100 and terminate using `break` at the first number divisible by both 7 & 11 (77). |
| **3** | **Search in List using `for-else`** | Search for a target value in a list, printing `"Number Found"` or `"Number Not Found"` via `for-else`. |
| **4** | **Enumerate Names** | Display indexed names (`1 Aman`, `2 Ravi`, etc.) using `enumerate(names, start=1)`. |
| **5** | **Half-Pyramid Pattern** | Print expanding star pattern (`*`, `**`, `***`, `****`, `*****`) using nested loops. |
| **6** | **Inverted Half-Pyramid Pattern** | Print inverted star pattern (`*****`, `****`, `***`, `**`, `*`) using nested loops. |
| **7** | **Multiplication Tables (1–10)** | Generate tables from 1 to 10 using nested `for` loops. |
| **8** | **Divisible by 3 and 5 (1–200)** | Find all numbers between 1 and 200 divisible by both 3 and 5 (multiples of 15). |
| **9** | **Remove Duplicates** | Filter duplicate elements from a list into a new unique list without using `set()`. |
| **10** | **Count Positives, Negatives, Zeros** | Categorize and count numbers in `[10, -4, 8, -2, 0, 15, -9, 21]`. |
| **11** | **Prime Number Checker** | Determine if a number is prime using a loop and early exit logic. |
| **12** | **Prime Numbers from 1 to 100** | Generate and collect all prime numbers between 1 and 100 using nested loops. |
